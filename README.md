# Каталог стеклянных бутылок

Статический сайт без серверной части. Можно размещать на GitHub Pages, Cloudflare Pages, Netlify и других хостингах статических сайтов.

## Структура
- index.html — главная страница и каталог
- style.css — оформление
- script.js — каталог, поиск, фильтры и карточки

## Перед публикацией
1. Замените телефон в `index.html`.
2. При необходимости замените название компании и тексты.
3. Добавьте реальные фотографии бутылок в `assets/images/` и замените блок `.mini-bottle` на `<img>`.
4. Подключите обработчик формы (почта/CRM/Telegram).
5. Для реального каталога замените демонстрационные позиции в массиве `products` на точные данные производителя.

Сайт сделан как готовая статическая основа; изображения и реквизиты производителя намеренно не выдумываются.
